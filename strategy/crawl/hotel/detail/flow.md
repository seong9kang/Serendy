# 호텔 정보 추출 방법

## 1. 구글 검색을 통해 홈페이지 URL 보정 
  - 구글 검색에 호텔 이름을 조회, 실제 홈페이지 위치를 찾아냄
  - 만약 data/hotels/list/lastest.json 에서 추출한 홈페이지가 다르면, 실제 URL을 업데이트
## 2. 실제 홈페이지에 접속 
  - 모든 접속은 chronium 을 기준으로 실제 크롬처럼 동작 & 렌더링 필수 & SPA 하이드레이션 대기
    - 1. shifter로 접속 시도 
    - 2. 실패시 useData 로 접속 시도
    - 3. 실패시 local 장비에서 접속지도
## 3. 실제 홈페이지 내용 크롤링
  - 루트에서부터 시작해서 필요시 링크를 따라 정보 수집
