# AI 기반 호텔 프로모션 & 여행 의사결정 플랫폼

## 사업 개요 및 단계별 전략

---

# 1. 사업 비전

현재 호텔 예약 시장은 Booking, Agoda, Expedia 등의 OTA(Online Travel Agency)가 장악하고 있다.

하지만 대부분의 플랫폼은 사용자가 이미 여행지와 일정이 정해진 상태에서 가격을 비교하고 예약하는 데 초점이 맞춰져 있다.

반면 실제 여행자들은 다음과 같은 고민에서 시작한다.


* 따뜻한 곳으로 가고 싶은데 어디가 좋을까?
* 직항으로 갈 수 있는 휴양지는 어디일까?
* 가족여행에 적합한 호텔은 어디일까?
* 지금 예약하는 것이 좋은 시점인가?
* 지금 가장 좋은 호텔 프로모션은 무엇인가?
* 포인트를 가장 효율적으로 사용할 수 있는 호텔은 어디인가?


본 서비스는 단순 호텔 검색 플랫폼이 아닌,

> **호텔 프로모션과 가격 데이터를 기반으로 최적의 여행 의사결정을 지원하는 AI 플랫폼**

을 목표로 한다.

장기적으로는 여행 예약 플랫폼이 아니라,

> **Travel Intelligence Layer (여행 의사결정 레이어)**

가 되는 것을 목표로 한다.

## 집중할 것

초기에는 아래 두 가지 문제 해결에 집중한다.

### 1. 체인 호텔 프로모션 모니터링

#### 사용자의 문제

* 좋은 프로모션을 놓친다.
* 어떤 체인의 프로모션이 좋은지 모른다.
* 포인트 사용 가치 계산이 어렵다.

#### 서비스 제공 가치

* 호텔 체인 프로모션 자동 수집

---

### 2. 조건 기반 역검색

#### 기존 방식

```text
목적지 선택 → 호텔 검색
```

#### 새로운 방식

```text
조건 입력 → AI 분석 → 목적지 추천 → 호텔 추천
```

#### 예시

* 12월에 따뜻한 곳
* 직항 가능한 휴양지
* 가족여행
* 골프 여행
* 허니문
* 리조트 여행
