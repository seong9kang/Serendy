# Serendy 비즈니스 모델 (요약)

> project.md / flow.md / api-comparison.md 에 흩어진 내용을 한 장으로 정리한 문서.

---

## 한 줄 정의

> **OTA를 만드는 게 아니라, 호텔 프로모션·가격 데이터를 축적해
> "어디로 갈지 / 언제 예약할지"를 AI가 도와주는 여행 의사결정 레이어(Travel Intelligence Layer).**

---

## 차별점 — 왜 Booking/Agoda가 아닌가

기존 OTA는 **"목적지·날짜가 이미 정해진 사람"**을 위한 검색 도구다.
Serendy는 그 앞단과 사후 관리를 공략한다.

| 사용자 상황 | 기존 OTA | Serendy |
|---|---|---|
| 어디 갈지 모름 | 도움 안 됨 | **조건 역검색** (조건 → 목적지 추천) |
| 좋은 프로모션을 찾고 싶음 | 흩어져 있음 | **프로모션 허브** (체인별 통합) |
| 날짜는 정했고 예약 시점이 고민 | 현재가만 보여줌 | **Trip Watch** (최적가 추적·알림) |

---

## 집중하는 3가지

1. **체인 호텔 프로모션 모니터링** — Marriott/Hilton/Hyatt/IHG/Accor 프로모션·포인트 통합 추적
2. **조건 기반 역검색** — 날씨·직항·목적 입력 → AI가 목적지+호텔 동시 추천
3. **여행 일정 기반 최적가 추적 (Trip Watch)** — [지역+날짜] 등록 → 최적가 시점 알림

### 안 하는 것
자체 커뮤니티 · AI 일정생성 · 맛집추천 · 관광지 종합플랫폼 · OTA 직접운영 · 항공권 판매
→ 강자가 이미 있어 초기 차별화가 어려운 영역. 호텔 프로모션·가격 데이터 한 우물에 집중.

## 수익 모델 (3단계)

| 단계 | 모델 | 내용 | 진입 난이도 |
|---|---|---|---|
| **1차** | 어필리에이트 커미션 | 추천 링크로 예약 발생 시 소개비. 재고·여행업등록 불필요, 위험 0 | 낮음 (지금 가능) |
| **2차** | 프리미엄 구독 (Trip Watch 포함) | 프로모션·가격 알림, 최적가 추적 무제한, 목표가 지정 | 중간 |
| **3차** | B2B 데이터 판매 | 축적된 가격·프로모션 시계열을 호텔/여행사/관광청에 판매 | 높음 (데이터 축적 후) |

### 어필리에이트란
내 사이트의 추천 링크(내 고유 ID 포함)로 사용자가 예약·숙박하면, 예약금의 일부를 소개비로 받는 제휴 구조.
호텔을 직접 팔지 않고 **손님을 보내주고 수수료를 받는다.** 재고·결제·CS는 OTA가 처리.
링크/위젯은 API 승인 없이 **가입만 하면 즉시** 사용 가능.

### Trip Watch — 수익 이중화 포인트
```text
[지역 + 여행 날짜 + 조건] 등록
   → 기간 내 호텔 가격 지속 모니터링
   → 최저가 시점 / 목표가 도달 / 새 프로모션 발생 시 알림
   → "지금 예약하세요" 신호
```
- 무료: 추적 1~2건 / 1일 1회 갱신
- 프리미엄: 추적 무제한 / 실시간 알림 / 다중 호텔 비교
- 최적가에 우리 링크로 예약 → **구독 수익 + 어필리에이트 수수료 동시 발생**
- 출발일까지 반복 방문·알림 수신 → **가장 강력한 리텐션 장치**

## 진짜 해자(moat)

**가격·프로모션 시계열 데이터.**
호텔 기본 데이터는 누구나 API로 산다. 그러나 "이 호텔이 시간에 따라 어떻게 변했는가"는
매일 수집해 쌓아야만 생기고, 시간이 지날수록 복제 불가능해진다.
→ 그래서 초기 목표는 화려한 서비스가 아니라 **꾸준히 도는 수집 파이프라인.**

---

## 운영 전략 (API)

```text
지금:  Amadeus(즉시 데이터 수집, 승인장벽 없음) + 어필리에이트 링크(수익채널 먼저 오픈)
다음:  트래픽·예약 실적 축적 → Agoda(아시아 핵심) → Booking Demand API 승인 → Expedia(선택)
```
- 데이터 즉시 수집: **Amadeus** (호출당 과금, 승인 불필요)
- 수익 즉시: **어필리에이트 링크** (API 불필요)
- 타깃(동남아 아웃바운드) 정합성: **Agoda** 최상
- 가격 장기 시계열 저장은 각 API **약관 검토 필수** (스크래핑은 법적 리스크로 후순위)
- 상세: [api-comparison.md](./api-comparison.md)

## 제품 로드맵 (flow.md 반영)

```text
첫 화면(조건 질문) → Promotions(MVP 핵심) → Hotel Detail(의사결정 화면)
        → Price Tracking / Trip Watch → (데이터 축적 후) AI 조건 역검색 본격화
```
- **MVP 우선순위:** 프로모션 허브 + 가격 추적/Trip Watch (= 매주 재방문 이유)
- 첫 화면은 호텔 목록이 아니라 **"어떤 여행을 계획하세요?" 질문**으로 시작 (OTA화 방지)
- 가장 중요한 화면은 첫 화면이 아니라 **호텔 상세** ("검색"이 아닌 "의사결정")
